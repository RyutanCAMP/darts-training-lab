# DARTS TRAINING LAB — 基本設計書
Version: 0.1 / 2026-10-10
Status: 初版（実機未検証）

## 1. 目的・基本思想
**投げるほど、自分の強みと弱点が見えてくる。**
スコアを楽しみながら1投単位の履歴を蓄積し、客観的な統計・将来のAI診断・投球動画を通して練習の改善サイクルを作る。

優先順位：**履歴 > 分析・AI診断 > ゲーム体験 > 演出**。
単なるDARTSLIVE HOMEの模倣ではなく、本人の過去の成功投球と比較して成長できる練習環境を目指す。

## 2. 対象環境と制約
- 初期：Windows 11、Chrome / Edge、単体HTML/CSS/JavaScript。インストール不要、オフラインで基本機能が動作。
- 対象ボード：DARTSLIVE-200S。Bluetooth入力の方式・キー割当・CHANGE/MISS検出可否は**実機で未確認**。自動採点は検証完了まで「試験機能」とする。
- iPhone動画は後日取り込み。PCカメラでの録画と着弾同期も将来検討。
- GitHubリポジトリは公開。個人の練習履歴・動画・APIキー・秘密情報をコミットしない。

## 4. 画面設計
### 4.1 全体ナビゲーション
1. **DASHBOARD**：直近平均、ブル率、投球順別ブル率、推移、最新の気づき、練習開始。
2. **PLAY**：COUNT-UPの大きな得点、ラウンド、残り投数、直近3投、入力、MISS、UNDO、NEXT、終了。
3. **HISTORY**：日付別セッション一覧、各24投の詳細、最高点、平均、ブル率、削除・エクスポート。
4. **ANALYSIS**：投球順別、期間別、成功/失敗の傾向。初期は統計表示、AI診断は後日。
5. **SETTINGS**：ボード入力テスト、音量、保存・復元、表示設定。

### 4.2 ビジュアル方針
- ダークネイビー〜チャコールをベースに、シアンとライム系アクセント。余白のあるスポーツ計測機器のようなUI。
- 数字を主役にした大型タイポグラフィ。グラフ・カードは整理し、過剰な発光や常時アニメーションを避ける。
- BULL / HAT TRICK / GAME START / TURN CHANGEは短い演出。操作と記録の妨げにならない。
- Windowsの標準画面を優先しつつ、狭い画面にも対応。操作ボタンは大きく、誤操作防止。
- 実測値、暫定値、AIによる推測は表示上も区別する。

## 5. COUNT-UP仕様（MVP）
- 8ラウンド × 3投、最大24投。累積得点を表示。
- シングル1〜20、ダブル、トリプル、アウターブル25、インナーブル50、MISS0。
- 投球ごとに記録して即時保存。各ラウンド3投で次ラウンドへ移行する（手動NEXT操作も用意）。
- 3投未満のNEXTは確認を求め、空き投を勝手にMISSとして補完しない。
- UNDOは直前の投球・ラウンド移行を安全に取り消す。履歴データとの整合性を維持。
- ボードで検知できない場外MISS、バウンスアウト等は手動入力で補正できる。
- 24投終了後は結果画面を表示し、セッション確定。途中終了は中断として保存し、完走記録と区別。
- 取り消し・修正は統計にも反映。ダブルカウントを防止する。

## 6. 記録データ設計
### Session
- id, schemaVersion, startedAt, endedAt, status (active/completed/abandoned), gameType (countup), source, score, notes
### Dart
- id, sessionId, roundIndex (1〜8), dartIndex (1〜3), timestamp, segment (例 S20/D20/T20/OB/IB/MISS), score, inputSource (manual/board), corrected, optional videoRef
### 保存
- v0.1：ブラウザのlocalStorageを暫定採用。起動時に読み込み、1投ごとに書き込む。
- 保存容量・ブラウザデータ消去・別PCとの非同期に注意。JSONのエクスポート/インポートをMVPに実装する。
- 後日、データ増加に合わせIndexedDBへ移行。schemaVersionで旧データを移行可能にする。
- 動画本体はGitHubやlocalStorageに格納せず、将来ローカルファイル/別ストレージで管理。

## 7. 集計・診断仕様
- 平均スコア：完走セッションのみを対象。
- ブル率：ブル（OB/IB）投数 ÷ 対象の記録済み投数。MISSも分母に含む。投球順別（1/2/3）で同じ定義。
- インナーブル率、ラウンド平均、最高点、練習日数、直近Nセッション推移を順次追加。
- 少数サンプルでは「参考値」と表示し、統計的に意味のある差と断言しない。
- AI診断は「測定事実」「解釈・仮説」「次の練習課題」「改善確認」を分離。スコアだけでフォームの原因を断定しない。
- 将来の動画診断は撮影角度、画質、タイミングの不確実性を明示。成功投球との比較を重視。

## 8. DARTSLIVE-200S入力検証
1. WindowsのBluetoothペアリングとブラウザの入力受信可否を実機確認。
2. キーイベントモニタで event.key / event.code / repeat / timestamp を表示。
3. S/D/T、OB/IB、MISS、CHANGE等の割当を実測し、ユーザーが校正・保存できるようにする。
4. 入力重複、長押し、ラウンド境界、アプリ非アクティブ時の挙動を確認。
5. HIDキーボード入力が不可能な場合はWebHIDまたはWindows側補助プログラムを別案として検討。**現時点では動作保証しない**。

## 9. 将来の動画・音声
- 動画：スマホ撮影の取り込み→日付/セッション紐付け→成功/失敗の比較→自動同期を段階導入。
- 音声：BULL、ゲーム開始、ターン変更等の独自制作SFXと、低音男性/かわいい女性/大会実況/落ち着いたコーチなど切替可能な音声。
- 公式DARTSLIVE音源・画像の無断コピーはしない。権利確認済み素材または自作音源を使用。
- AI音声生成や外部AIサービスは利用料金、通信、APIキー保護を設計したうえで後日実装。

## 11. 品質・受け入れテスト
- 24投の合計、ブル25/50、D/T倍率、MISS0、ラウンド番号を検算。
- UNDO、NEXT、途中終了、再読み込み、完走保存、過去履歴表示を確認。
- 記録後にブラウザを閉じても復元できることを確認。
- JSONのエクスポート→インポートで同じスコアと投球順を再現。
- 不正データや保存失敗をユーザーに知らせ、既存履歴を破壊しない。
- Windows Chrome/Edgeで操作し、キーボードとマウスの両方で使える。
