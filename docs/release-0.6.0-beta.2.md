# v0.6.0-beta.2 — CHECKOUT guide

- 01の残点が180以下になると、得点エリアの右上に小さく上がり方を最大3候補表示する。
- 残り20ならS20 / D10、50ならBULL、残り61・2投ならBULL + S11など。
- 現行ルール（オープンアウト、OB/IBとも50点）で、ラウンド内の残り投数でちょうど0にできるルートだけを表示する。
- 少ない投数の候補を優先。同じ投数ではシングル、ブル、ダブル、トリプルの順に組み合わせの負担を評価する。成功確率や個人の得意エリアを推定した推薦ではない。
- 投球、MISS、バースト、undo、再読込に追従。ラウンド切替後は次ラウンドの3投で計算し、終了後・COUNT-UPでは非表示。
- 180以下でも残り投数で届かない場合は、候補がないことを明示。25点のブルとして計算しない。
- 保存データ・クラウド形式は変更なし。ソースと単独previewのバージョンを更新。
