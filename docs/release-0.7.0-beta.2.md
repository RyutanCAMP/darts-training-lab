# v0.7.0-beta.2 — ゲスト初期名とアカウント選択

- 対戦準備の名前は最初から「プレーヤー1」「プレーヤー2」。変更せずに開始できる。ゲスト名の編集も可能。
- 各プレイヤーの選択欄に「ゲスト」と、現在ログイン中のアカウントを表示する。未ログインならゲストのみ。
- ログイン中のアカウントはP1/P2のどちらか1人へ割り当てる。同じアカウントを反対側に選び直すと、元の側はゲストへ戻る。
- アカウント選択時の名前はログイン名（最大20文字）で読み取り専用。ゲストに戻すと、変更前のゲスト名を復元する。
- フォームを開いている間のログアウト・別アカウントへの切替では、以前の選択をゲストへ戻す。進行中・保存済みの対戦や名前は変更しない。
- 記録は名前とは別に、任意の`players[i].account: {provider:'google',uid}`を持つ。既存の名前だけの記録も読める。再戦・途中再開・JSON履歴バックアップでも割当を保持する。
- この情報は端末内の対戦参加者のスナップショットであり、認証の証明やアクセス権限として使わない。accountフィールドはプロバイダとUIDのみで、認証トークンを保存しない。
- 他人のアカウント一覧や2人同時ログインは対象外。2人対戦記録は引き続きクラウド同期対象外。
