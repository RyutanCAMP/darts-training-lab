## 実装済み

- COUNT-UP（既存）、分析、200S入力、MY DARTS、クラウド同期（既存）。
- 01: 301 / 501 / 701、ストレートイン、オープンアウト、ブル50点、20ラウンド。バースト、取り消し、途中再開、履歴、バックアップ、上がり候補。
- 2人対戦（01・クリケット共通）: 1台で交代。P1先攻。3投（01はバーストでも）で交代確認、ボタンまたは200S CHANGE。名前の初期値は「プレーヤー1」「プレーヤー2」。ログイン中のアカウントを片方にだけ割り当て可能。2人対戦は端末保存のみでクラウド同期・COUNT-UP分析の対象外。
- クリケット（`docs/release-0.9.0-beta.1.md` に詳細）:
  - 対象は20〜15とBULL。S=1、D=2、T=3マーク、アウターブル1・インナーブル2マーク、ブル1マーク25点。
  - 3マークでクローズ。相手が未クローズの数字への追加マークは得点。両者クローズの数字は得点もマークもなし。
  - 2人: 全部閉めて点数が相手以上なら即勝ち。15ラウンド終了時は点数の多い方、同点は引き分け。
  - 1人: 全部閉めるか15ラウンドで終了。MPR＝有効マーク数÷投数×3。
  - 各投の `score` はその投で得たクリケット点。再生時に一致を検証する。
  - 1人用クリケットは1人用01と同じくクラウド同期対象。COUNT-UP分析には入らない。
- 横向き中心の画面: 中央ボード、左にラウンド（クリケットはマーク表）、右に3投と操作、下に得点。縦向き・スマホ横向きにも対応。

## 開発と公開

```sh
python -m pip install playwright
python -m playwright install chromium
python tools/serve-preview.py
python -X utf8 tools/run-tests.py
python tools/sync-preview.py --check
git diff --check
```

- Windowsでは `python -X utf8` を付けて実行する（cp932でエラー詳細が出ないため）。
- テストは合成データを使用し、ユーザーのブラウザ保存データを操作しない。テスト生成物（`.test-artifacts/`）、仮想環境、`debug.log`、個人練習記録はコミットしない。
- GitHub Actions: mainへのpushでテスト後に本番公開。PRではテスト後にFirebaseのプレビューURL（30日）を作る。ブランチへのpushでは何も動かない。PR作成・マージ・デプロイはユーザーに確認してから行う。
