# v0.7.0-beta.1 — 2人のローカル対戦

## 開始の流れ

PLAYの「2人対戦」から、最初にプレイヤー1・2の名前（各1〜20文字）を入力し、301 / 501 / 701を選んで開始する。名前の入力前には対戦を始めない。
既存ゲームに投球がある場合は、途中終了または確定結果として保存する確認を経る。キャンセルすれば既存ゲームを続けられる。

## ルールと操作

- 1台・1ボードを2人で交代して使う01。P1先攻、ブル50点、オープンアウト。
- 3投またはバーストで交代待ち。「交代して投げる」または200S CHANGEで次の人が開始。交代待ちの着弾は記録しない。
- バーストはその人のラウンド開始時の残点へ戻し、相手の残点には影響しない。
- 先にちょうど0にした人が勝ち。各20ラウンド、P2の最終手番まで誰も上がれなければ引き分け。
- 取り消しで、上がり・バースト・プレイヤー交代をまたいで直前の状態へ戻る。
- 再読込で名前・各残点・投球順・交代待ちを復元する。再戦は同じ2人、名前を変える場合は「2人対戦」で再設定する。「1人練習へ」でソロに戻れる。
- 上がり候補は現在のプレイヤーの残点と残り投数で計算し、得点の右上に小さく表示する。

## 記録の互換性と保存先

- `gameType:'zero-one'`を維持し、2人対戦にだけ`players`を追加。dartの`playerIndex`は0/1、`roundIndex`は両者とも1〜20。`readyTurn`は手番交代の確認済み位置。
- `result`にwinner（0/1、引き分けはnull）とscores（両者の残点）を保存し、読み込み時の検証では投球列から再計算する。
- 保存キーやCOUNT-UP、1人用01の既存形式は維持。2人の記録を1人用の分析へ混ぜない。
- 2人対戦の履歴はこの端末内に保存し、Googleログイン中でもクラウド同期の送受信・未同期件数から除外する。
- JSONバックアップで対戦履歴を出力・復元できる。CSV末尾にplayer_index / player_nameを追加し、カンマ・引用符を含む名前も引用処理する。
- 名前はHTMLとして解釈しない。画面に表示する場合はテキスト化またはエスケープする。
- ネットワーク対戦は含まない。ページを開いた後の対戦操作はネット接続不要。通常の公開ページには従来どおりオフラインキャッシュがないため、ネットなしでの再起動には単独preview.htmlを使う。
